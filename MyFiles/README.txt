ملفاتي — مدير ملفات أندرويد (Kotlin + Jetpack Compose)

التشغيل:
1) فك الضغط وافتح الفولدر في Android Studio (Hedgehog أو أحدث) واستنى الـ Gradle Sync.
2) وصّل التليفون (USB debugging) واضغط Run ▶  أو Build > Build APK.
3) أول مرة التطبيق هيطلب صلاحية "الوصول لكل الملفات".

للوصول لـ Android/data و Android/obb:
- نزّل تطبيق Shizuku وشغّله (Wireless debugging أو root) ثم من الرئيسية اضغط "طلب الصلاحية".

المميزات: أقسام (صور/فيديو/أغاني/نصوص/بايثون/HTML/مستندات/مضغوطات/APK)،
مجلدات مهمة في القائمة الجانبية، محرر نصوص وأكواد، مشغّل فيديو وأغاني داخلي مع قائمة تشغيل،
عارض صور، نسخ/قص/لصق/حذف/إعادة تسمية/بحث.
